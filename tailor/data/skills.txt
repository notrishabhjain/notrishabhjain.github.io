# Tailor skills taxonomy
#
# One skill per line:
#   Name = swap-safe forms | match-only forms ^ Parent, Parent ~ Related, Related
#
#   =   forms that mean exactly the same thing and can replace each other in a
#       bullet (acronym <-> expansion, word-order variants). Keep this short.
#   |   forms that are recognised in a job description but never written in.
#   ^   broader skills. A JD asking for the broader skill gives partial credit
#       to evidence of this one, and the other way round.
#   ~   related skills: partial credit, never swapped.
#
#   *Name      an abstract group. Skills under it are not related to each other
#              just because they share it (Java and Python are both languages).
#   form!      case-sensitive.
#   form!!     case-sensitive and ignored at the start of a sentence
#              ("Spark" the engine, not "spark" the verb).
#   All-caps forms of four letters or fewer are case-sensitive automatically.
#
# UK and US spellings, plurals, hyphens and word order ("managing vendors",
# "vendor management") are normalised by the matcher, so list one spelling only.
# Lines starting with @ set the category for the lines below them.
