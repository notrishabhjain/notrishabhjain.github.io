# Rishabh Jain · international portfolio (`international` branch)

This branch holds a **separate** version of the portfolio for international and freelance
hiring: multi-page, USD figures, case studies with charts, and a Services page. The
India-focused site on `master` is untouched and stays live at notrishabhjain.github.io.

## Pages
- `/` home · `/work/` all projects with filters
- `/work/pay-commission-platform/`, `/work/green-hydrogen-certification/`,
  `/work/wind-portfolio-turnaround/`, `/work/cooperative-registry/`: full case studies with charts
- `/experience/` · `/services/` · `/about/` · `/contact/`

## Editing
Pages are generated by `tools/build.py` (content) with `tools/charts.py` (inline SVG charts)
and `tools/layout.py` (header and footer). Edit there, run `python3 tools/build.py`, commit the
generated HTML. Styles are in `assets/css/site.css`, and fonts are self-hosted.

All links are relative, so the site works at a domain root or under a `/repo-name/` path.
INR figures are converted at about ₹87 = $1.

## Why there is no deploy workflow here
The master site deploys to GitHub Pages from `master`. A user site can only serve one
deployment, so a workflow on this branch would overwrite the live site. To publish this
version alongside it, do one of the following:
1. Create a second repository (for example `notrishabhjain/portfolio`), push this branch to it
   as `main`, and enable Pages there. It is then served at `notrishabhjain.github.io/portfolio/`.
2. Point a custom domain at that second repository.

Then update `SITE` in `tools/layout.py` (used for the sitemap and canonical data) and rebuild.
