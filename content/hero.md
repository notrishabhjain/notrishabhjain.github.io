carry the claim, the proof, and the action without requiring a single scroll.

## Notes on this screen

- **The key sentence changed.** The old draft said "I read the code and I sit in the
  steering committee." You flagged it as only partly true — you have a tech lead. The
  new version says exactly that and turns it into the stronger claim: not that you do
  the engineer's job, but that nothing has to be translated for you. That's the accurate
  version *and* the better one, because "I still write the code" from a manager invites
  a follow-up question you don't want.
- **The four numbers now cover four different things** — tenure, scale, speed, and
  commercial outcome. That range is deliberate: it pre-empts the "great delivery guy,
  but does he understand the money" question before anyone asks it.
- **No photo.** You said skip, so the page carries itself typographically. That's a
  legitimate choice and increasingly common, but worth knowing it is a choice: for an
  employer audience a face slightly raises reply rates on outreach. Easy to add later
  if you change your mind.
- **No slider, no typed job titles.** Both were on the old site. Both read as filler to
  a senior reader, and filler is what an eight-second screen cannot afford.
